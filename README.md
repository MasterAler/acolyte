# Аколит — голосовой писарь для Jitsi-созвонов

Сидит на встрече, слушает команды, пишет через OBS, после встречи делает
транскрипт (faster-whisper) и выжимку (локальный Ollama). Всё на твоей машине,
никакие аудио наружу не уходят.

## Как это устроено

```
микрофон ──► Vosk (стриминг) ──► «Аколит, …» ──► obs-websocket ──► OBS пишет mkv
                                                              │
«Аколит, конец» ──► mkv ──► 2 дорожки (mic/desktop) ──► faster-whisper
                              ──► transcript.md ──► Ollama (map-reduce) ──► summary.md
```

Дорожка микрофона — твой голос («Я»), дорожка системы — все остальные
(«Участник»). Разделение по каналам вместо нейтральной диаризации: дёшево и
надёжно, но кто именно из участников говорил — неизвестно.

## Команды

| Команда | Действие |
|---|---|
| «Аколит, запись» | начать запись / продолжить после паузы |
| «Аколит, стоп» | пауза (оффтоп не пишется) |
| «Аколит, это решение» | маркер: близкий диалог (±90 с) попадёт в раздел «Решения» |
| «Аколит, это оффтоп» | включить/выключить оффтоп-режим до следующего маркера |
| «Аколит, отмена» | снять последний маркер |
| «Аколит, конец» | закончить: стоп записи → транскрипт → выжимка |

Хоткеи (если `hotkeys = true`): Ctrl+Alt+J запись/пауза, +S решение, +O оффтоп, +K конец.

Подтверждение — писк (+ короткая фраза, если есть русский голос SAPI).
Пока Аколит сам говорит, команды с микрофона игнорируются (защита от эха).

## Установка

```bash
git clone https://github.com/MasterAler/acolyte.git && cd acolyte
py -3.11 -m venv .venv
.venv\Scripts\pip install -e ".[voice]"
.venv\Scripts\python install_models.py     # модель Vosk (~45 МБ)
copy acolyte.toml.example acolyte.toml     # и вписать пароль OBS, если задан
.venv\Scripts\acolyte doctor               # проверка всей цепочки
```

Whisper-модель (~1.6 ГБ) скачается сама при первом «конец».

## Настройка OBS (один раз)

1. **Настройки → Вывод → Запись**: формат **Matroska (mkv)**, в «Audio Tracks»
   включить **1 и 2**. «Automatic File Splitting» — выключить.
2. **Микшер → ⋮ → Advanced Audio Properties**: Mic Aux → только Track 1;
   Desktop Audio → только Track 2.
3. **Инструменты → Настройки WebSocket-сервера**: включить, порт 4455,
   пароль (если задаёшь — вписать в `acolyte.toml`).
4. Захват звука системы: в Windows включить стереомикшер или использовать
   «Audio Output Capture (WASAPI)» как источник Desktop Audio — тогда звук
   Jitsi из браузера попадает на Track 2.

Проверка: `.venv\Scripts\acolyte doctor --probe` (сделает 3-сек пробную запись).

## Запуск

```bash
.venv\Scripts\acolyte serve            # перед встречей; OBS поднимется сам, если не запущен
```

После «Аколит, конец» (или Ctrl+C → Y) в `sessions/<дата>/` появятся:
`markers.jsonl`, `transcript.md`, `transcript.jsonl`, `summary.md`, `map_results.json`.

Отдельные шаги для готовой сессии:

```bash
.venv\Scripts\acolyte transcribe sessions\2026-11-19_14-30_00
.venv\Scripts\acolyte summarize  sessions\2026-11-19_14-30_00
.venv\Scripts\acolyte publish    sessions\2026-11-19_14-30_00 --confluence --rag
.venv\Scripts\acolyte test-ear   # тренировка команд без OBS
```

## Публикация

- `--confluence` — черновик страницы в Confluence Server/DC. Параметры в
  `acolyte.toml [confluence]` (PAT-токен).
- `--rag` — дописывает выжимку в `~/.codex/tools/memory-rag/.data/acolyte.jsonl`;
  индексация — твоим обычным пайплайном memory-rag (`build_index.py`).

## Ограничения (честно)

- Пауза/запись, нажатые руками в OBS, ломают пересчёт таймкодов маркеров —
  командуй голосом.
- Преролла нет: «Аколит, запись» начинает с момента команды.
- Имена участников не определяются (диаризация v2, если понадобится).
- Транскрипт 4-часовой встречи на RTX 3060 (turbo int8) ~15–25 минут.
- Vosk small иногда слышит «акколит»/«а колит» — matcher это прощает; если
  будут ложные срабатывания, подними `WAKE_THRESHOLD` в `commands.py`.
